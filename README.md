# Portal De Comunicados Internos

Sitio interno de comunicacion institucional para anuncios operativos, alertas y publicaciones destacadas de la red logistica.

## Uso

1. `npm install`
2. `npm run dev`

Incluye buscador, filtros, prioridad, panel de detalle y suscripcion local a alertas internas.
## Modos de uso

- Desarrollo: `npm install && npm run dev`
- Archivo estatico: ejecuta `npm run build` y abre `index.html` en la raiz del proyecto.
